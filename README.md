# Iron Brotherhood Website

A modern, fully responsive website for Iron Brotherhood — a weekly men's workout and devotion community.

> "As iron sharpens iron, so one person sharpens another." — Proverbs 27:17

**[View the Website](https://fitnessforjesus.github.io/iron-brotherhood-website/)**

## 📚 Repository

**[GitHub Repository](https://github.com/fitnessforjesus/iron-brotherhood-website)**

## 🎨 Design System

### Colors
- **Iron** (`#111111`) - Primary dark background
- **Forge** (`#7a1508`) - Deep red accent
- **Ember** (`#C0392B`) - Bright red primary
- **Gold** (`#B8960C`) - Text accent
- **Light** (`#f5f0e8`) - Primary text

### Typography
- **Display Font**: Bebas Neue (titles, labels, buttons)
- **Body Font**: Crimson Pro (paragraphs, body text)

## 📋 Pages

- **Home** - Hero section with mission statement and call-to-action
- **Join** - Three-step guide to joining Iron Brotherhood
- **Calendar** - Weekly workout schedule with times and locations
- **Contact** - Contact form for inquiries

## ✨ Features

- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Smooth page transitions and animations
- ✅ Mobile-friendly hamburger navigation
- ✅ Grid-based responsive layout
- ✅ Glassmorphism navigation bar
- ✅ No build tools required — pure HTML/CSS/JS

## 🚀 Getting Started

### Local Development
1. Clone the repository
   ```bash
   git clone https://github.com/fitnessforjesus/iron-brotherhood-website.git
   cd iron-brotherhood-website
   ```
2. Open `index.html` in your browser
3. No build tools required!

### Deploy to GitHub Pages
This repo is configured for GitHub Pages. Simply push changes to the `main` branch and the site will auto-deploy.

## 📱 Responsive Breakpoints

- **Desktop**: 1000px max-width centered layout
- **Tablet**: Full width with adjusted spacing
- **Mobile**: Single column, hamburger navigation

## 🛠 Development

### File Structure
```
iron-brotherhood-website/
├── index.html          # Main website file (HTML + CSS + JS)
├── README.md           # This file
└── .gitignore          # Git ignore rules
```

### Customization

All styles are contained in the `<style>` tag within `index.html`. Update CSS variables in the `:root` selector to change colors:

```css
:root {
  --iron: #111111;      /* Dark background */
  --ember: #C0392B;     /* Primary red accent */
  --light: #f5f0e8;     /* Light text */
}
```
